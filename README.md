# Welcome to Swadeshi Mela
📖 Overview

Swadeshi Mela is a web-based platform designed to promote local businesses, artisans, and cultural events. The application allows users to explore events, register for participation, and enables administrators to manage events, bookings, categories, and content through a centralized dashboard.

✨ Features
User Side
Browse upcoming events
View event details
Register for events
Contact organizers
Responsive design for all devices
Admin Panel
Secure Admin Authentication
Dashboard with event statistics
Event Management (Create, Update, Delete)
Category Management
Booking Management
User Management
Content Management
Image Upload & Management
